## Sobre o Projeto
Interface web estática desenvolvida como um guia para o jogo Cuphead. O projeto documenta estratégias baseadas na análise de padrões (Finite State Machines) dos chefes e inclui um checklist de conquistas. 

O objetivo técnico da aplicação é demonstrar a aplicação prática de métricas de engenharia front-end, priorizando desempenho, usabilidade, estruturação semântica e acessibilidade.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização modular com variáveis globais, Flexbox, CSS Grid e efeitos visuais nativos, sem a utilização de frameworks externos.

## Métricas de Qualidade
O projeto foi submetido a auditorias para validação técnica dos requisitos:
* **Google Lighthouse (Mobile):** Acessibilidade (100), SEO (100), Best Practices (96), Performance (90).
* **W3C Validator:** Código HTML5 e folha de estilos CSS3 validados sem erros.
* **Responsividade:** Layout fluido adaptável a resoluções Mobile, Tablet e Desktop (abordagem Mobile-First).
